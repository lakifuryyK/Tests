# Дневник репетитора

Веб-приложение на Flask для ведения расписания, списка учеников и учёта платежей частного преподавателя.

## Возможности

- Добавление и просмотр учеников с контактами и заметками.
- Планирование занятий: дата, время, длительность, тема, статус и домашнее задание.
- Учёт оплат по ученикам с указанием способа и комментариев.
- Главная страница с ключевыми показателями и ближайшими занятиями.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
flask --app tutor_diary.app init-db
flask --app tutor_diary.app run
```

Приложение будет доступно по адресу http://127.0.0.1:5000.

## Структура проекта

```
tutor_diary/
├── __init__.py        # фабрика приложения, настройки и регистрация blueprints
├── app.py             # точка входа для запуска через python -m tutor_diary.app
├── models.py          # SQLAlchemy-модели (ученики, занятия, платежи)
├── templates/         # HTML-шаблоны интерфейса
└── static/css/        # Стили оформления
```

- Подключите Flask-Migrate для управления миграциями.
- Реализуйте экспорт отчётов и напоминания о занятиях.
