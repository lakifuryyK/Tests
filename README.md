# ОбразОн — дневник для репетитора и ученика

Веб-приложение на Flask для ведения расписания, списка учеников и учёта платежей частного преподавателя с отдельным кабинетом ученика.

## Возможности

- Добавление и просмотр учеников с контактами, заметками и учётными данными.
- Планирование занятий: дата, время, длительность, тема, статус и домашнее задание.
- Учёт оплат по ученикам с указанием способа и комментариев.
- Главная страница «ОбразОн» с ключевыми показателями, интерактивным календарём преподавателя и помощником недели.
- Личный кабинет ученика с интерактивным календарём, домашними заданиями, материалами и чат-каналом.
- Расширенное управление по каждому ученику для преподавателя: чат, ДЗ, материалы, история платежей и уроков на одной странице.
- Встроенное уведомление о cookie с хранением согласия в файле cookie браузера.
- Автоматическое определение роли при входе: преподаватель и ученики используют одну форму авторизации.
- Блок «Контроль оплат» подсказывает, какие ученики давно не подтверждали платежи.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
flask --app tutor_diary.app init-db
flask --app tutor_diary.app run
```

Приложение будет доступно по адресу http://127.0.0.1:5000.

### Учётные данные по умолчанию

- преподаватель: `admin` / `admin` (создаётся автоматически при первом запуске);
- каждый ученик получает свой логин и пароль при создании (максимум 10 учеников).

## Структура проекта

