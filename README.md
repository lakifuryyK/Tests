# ОбразОн — дневник для репетитора и ученика

Веб-приложение на Flask для ведения расписания, списка учеников и учёта платежей частного преподавателя с отдельным кабинетом ученика.

## Возможности

- Добавление и просмотр учеников с контактами, заметками и учётными данными.
- Планирование занятий: дата, время, длительность, тема, домашнее задание, стоимость и статус оплаты.
- Учёт оплат по ученикам с автоматическим подсчётом по выбранным урокам и привязкой платежей к занятиям.
- Главная страница «ОбразОн» с ключевыми показателями, расширенным календарём преподавателя и помощником недели.
- Личный кабинет ученика с интерактивным календарём, домашними заданиями, материалами и чат-каналом.
- Расширенное управление по каждому ученику для преподавателя: чат, ДЗ, материалы, история платежей и уроков на одной странице.
- Гибкие предметные настройки под контролем администратора: цвета, описания и рекомендованная длительность урока с привязкой учеников к предметам.
- Каждый преподаватель работает максимум с тремя предметами из общего каталога — администратор назначает направления и может обновлять их в любой момент.
- Общая библиотека материалов с фильтрами и быстрым прикреплением ресурсов к ученикам.
- Встроенное уведомление о cookie с хранением согласия в файле cookie браузера.
- Автоматическое определение роли при входе: админ, преподаватели и ученики используют одну форму авторизации.
- Отдельная административная панель: управление преподавателями, ограничениями и удалением/переназначением учеников.
- Блок «Контроль оплат» и личный помощник показывают учеников с неоплаченными занятиями и объём задолженности.
- Центр коммуникаций администратора: массовые рассылки преподавателям, адресные сообщения по предмету, прямые сообщения ученикам и лента последних объявлений.
- Панели преподавателя и ученика отображают свежие объявления «ОбразОн» с подсветкой важных дедлайнов.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
flask --app tutor_diary.app init-db
flask --app tutor_diary.app run
```

Приложение будет доступно по адресу http://127.0.0.1:5000.

### Учётные данные по умолчанию

- администратор системы: `admin` / `admin` (создаётся автоматически при первом запуске);
- преподавателей назначает администратор и задаёт им лимит учеников;
- каждый ученик получает свой логин и пароль при создании преподавателем или админом.

### Предметы по умолчанию

При инициализации базы данных «ОбразОн» автоматически добавляет базовый набор школьных
дисциплин (математика, русский язык, литература, английский язык, физика, химия,
биология, история, обществознание, география и информатика). Администратор назначает
каждому преподавателю ровно три предмета из каталога и может расширять перечень
дисциплин через панель управления.

## Структура проекта

```
tutor_diary/
├── __init__.py        # фабрика приложения, настройки и регистрация blueprints
├── app.py             # точка входа для запуска через python -m tutor_diary.app
├── models.py          # SQLAlchemy-модели (админ, преподаватели, ученики, занятия, платежи и библиотека)
├── templates/         # HTML-шаблоны интерфейса
└── static/
    ├── css/           # Стили оформления
    ├── img/           # Логотип и прочие графические элементы
    └── js/            # Клиентские сценарии (cookie-баннер и пр.)
```
